# scratch/ — Script thử nghiệm / debug

Thư mục chứa các script tạm thời được viết trong quá trình phát triển. Không thuộc pipeline chính và **không cần thiết** để chạy ứng dụng.

| File | Mục đích |
|------|----------|
| `check_models.py` | Kiểm tra sự tồn tại và kích thước của các file model (debug) |
| `train_kmeans.py` | Retrain thủ công mô hình KMeans Fallback trên toàn bộ dataset |
